Human-interactive robot learning is an area that sits at the intersection between human-robot interaction and robot learning, in which robots learn from interaction with humans. This is important for finetuning purposes, learning efficiency purposes, and safety purposes. This is an interdisciplinary area combining interactive machine learning techniques, interaction design, pedagogical studies, user behavior modeling, and empirical suer studies.
