In this seminar course we will unveil the foundations of software language engineering by diving into the details of the design, implementation, and evolution of software languages. Students will be developing their own DSL and their tooling. Upon completion of the course, students will get an understanding of most of the following topics:Implement a fully-fledged software language and its tooling (e.g., IDE). How to conduct a domain-analysis.How to design and implement the concrete and abstract syntax of a software language using grammarware and modelware technologies.How to design and implement the semantics of software languages.How to use and create tools for a software language.Type checkersEditorsIDE services (e.g., syntax highlighting, auto-completion, folding)Use parser generator technologies.Understand and apply model-to-model transformations.Understand and define code-generators to produce executable code.Usage of different language workbench technologies (e.g., Rascal, Eclipse EMF, and Jetbrains MPS).
