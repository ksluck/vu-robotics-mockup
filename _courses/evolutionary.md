This course teaches the principles and techniques of evolutionary computing and evolutionary robotics, with the following objectives: To learn about computational methods based on Darwinian principles of evolution. To understand the role of different forces behind an evolutionary process and the role of specific components of an evolutionary algorithm. To use evolutionary algorithms as problem solvers in optimization and machine learning and techniques to design embodied intelligence. To determine adequate algorithm setups depending on the problem at hand. To gain hands-on experience in performing computational experiments with evolutionary algorithms working in a team. To use the ARIEL simulator, a Python package that provides efficient and easy-to-use tools for evolutionary computing and evolutionary robotics (https://github.com/ci-group/ariel).
